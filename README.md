# Funcionalidade

Essa solução permite adaptar o layout de impressão de um agendamento no e-SUS Regulação para impressoras térmicas.

## Instalação

Após ter acesso à pasta da aplicação, carregue-a como extensão do Google Chrome. Para fazer isso, vá até a página de gerir extensões do Google, ou cole esse endereço na barra de URL: "chrome://extensions/". A seguir, habilite a opção "Modo de programador" no canto superior direito, carregue a extensão em "Carregar expandida" e selecione a pasta da aplicação "TÉRMICA E-SUS". 

Vá até o site do e-SUS Regulação, clique no ícone de extensões na barra superior do Google para expandir suas extensões, clique na extensão "TÉRMICA E-SUS" para permitir seu acesso ao site e fixe a extensão clicando no ícone de fixar.

## Utilização

Para utilizar, ao realizar um agendamento, clique no ícone de impressora 🖨️ da aplicação e clique no botão "Imprimir".

## Lembrete

Para que o layout funcione bem, recomendo que a sua impressora esteja configurada para uma impressão de no mínimo 12cm de altura.
